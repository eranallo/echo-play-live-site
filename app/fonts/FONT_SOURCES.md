# Website font sources

Selected by Evan on September 9, 2026: Cabinet Grotesk as primary website type and the After Hours palette. Web selected DM Sans for readable supporting copy and controls.

- Cabinet Grotesk variable webfont and static Bold TrueType: [official specimen](https://www.fontshare.com/fonts/cabinet-grotesk), [official webfont API](https://api.fontshare.com/v2/css?f[]=cabinet-grotesk@variable&display=swap), [Fontshare license terms](https://www.fontshare.com/licenses).
- DM Sans variable Latin webfont and static Regular TrueType: [official specimen](https://fonts.google.com/specimen/DM+Sans), [OFL source](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt). The license is retained as DMSans-OFL.txt.
- Existing supplied Gotham-Bold.ttf is preserved as historical brand source. Its earlier license/subsetting handling is not transferred to the new fonts.

Web headings default to Cabinet Grotesk 600, with existing page-specific weights retained. Body copy uses DM Sans 400; navigation and controls use 500–700. PDFs and generated previews use Cabinet Grotesk Bold and DM Sans Regular static files for renderer compatibility. Local files avoid third-party font requests from visitors.
